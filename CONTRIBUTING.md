# Contributing

Thanks for your interest in Todav!

## Ideas, bugs and questions

They are very welcome. Open an [issue](https://github.com/SelfRef/todav/issues) for a bug or a
concrete feature request, or a [discussion](https://github.com/SelfRef/todav/discussions) for
ideas and questions. For bugs, mention your Nextcloud and GNOME versions and how to reproduce
the problem.

## Pull requests

Please **don't open a pull request before the change has been agreed** in an issue or
discussion. Todav is developed along a plan, and an unannounced pull request may clash with work
in progress or go in a different direction, so it might not be merged. Describe what you'd like
to change first; once we agree on it, a pull request is welcome.

When you open one:

- Keep it to one change, and follow the style of the surrounding code.
- Run `cargo fmt`, `cargo clippy` and `cargo test`.
- Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages, e.g.
  `fix(linux): keep the scroll position when ticking a task`.
